📖 使用说明

这是一款完全免费的在线图片压缩工具，所有处理都在您的浏览器本地完成，无需上传图片到任何远程服务器，最大程度保护您的隐私安全。无论您是需要压缩证件照上传到各类平台，还是优化网站图片提升加载速度，本工具都能帮您轻松实现。

  • 步骤一：点击上传区域或将图片拖拽到虚线框内，支持 JPEG、PNG、WebP、BMP 等主流图片格式。
  • 步骤二：拖动质量滑块调整压缩强度（数值越低，压缩率越高，文件越小）。
  • 步骤三：选择输出格式，推荐使用 WebP 格式，在保持画质的同时大幅减小文件体积。
  • 步骤四：点击「重新压缩」预览效果，满意后点击「下载压缩图片」保存到本地。

适用场景：网站图片优化加速、社交媒体头像上传、电商商品图压缩、证件照文件大小调整、邮件附件瘦身、WordPress/博客图片优化等。

❓ 常见问题

图片会被上传到服务器吗？▼

不会。本工具完全在您的浏览器本地运行，使用 HTML5 Canvas API 进行图片压缩处理。您的图片从始至终都在您的设备上，不会被上传到任何第三方服务器。即使您断开网络连接，本工具依然可以正常使用。

哪种输出格式最好？▼

推荐使用 WebP 格式。WebP 是 Google 推出的现代图片格式，在同等画质下比 JPEG 小 25%-35%，比 PNG 小 26%-45%。目前主流浏览器（Chrome、Edge、Firefox、Safari）均已全面支持 WebP。如果需要最大兼容性（如老旧系统），可以选择 JPEG。

压缩质量设置多少合适？▼

一般建议设置在 70%-85% 之间。这个区间可以在肉眼几乎看不出差异的情况下，减少 50%-80% 的文件大小。如果是证件照等对清晰度要求较高的场景，建议设置在 85%-95%。如果只是用于网页展示，60%-75% 通常足够了。

支持批量压缩吗？▼

当前版本暂不支持批量压缩。如需批量处理多张图片，建议多次使用本工具或使用专业桌面软件。我们正在开发批量压缩功能，敬请期待。

压缩后图片尺寸会变化吗？▼

不会。本工具在压缩过程中保持图片的原始分辨率（宽度和高度）不变，仅通过调整编码质量来减小文件大小。如果您需要同时调整图片尺寸，请使用我们的图片缩放工具（即将推出）。

在线压缩图片会损失画质吗？▼

在合理压缩质量下（70%以上），肉眼几乎看不出差异。本工具支持质量滑块从 10% 到 100% 自由调节，您可以通过左右对比预览功能，实时查看压缩前后的画质变化，找到文件大小和画质的最佳平衡点。

最大可以压缩多大的图片？▼

本工具支持最大 50MB 的图片文件。由于所有处理都在浏览器本地完成，大文件也能快速压缩，无需等待上传。支持 JPEG、PNG、WebP、BMP 等多种格式。
